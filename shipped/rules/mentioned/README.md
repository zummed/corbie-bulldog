Mentioned: a team's heed that acts on what names the bot or follows straight on its answer, and notes the rest, with no model.

It acts when a message it weighs is marked as naming the bot, as the shipped Slack bridge marks one, or comes straight after the lead's answer and is said by whoever that answer went to. Anything else it notes, with "Not addressed to <lead>.". It acts if any one message it weighs is addressed.

## Needs

Nothing: no secret and no host. It is a bare script, which runs with no permission.

## Settings

None.

## Example

```yaml
# in a team file
heed: ./.bulldog/rules/mentioned/mentioned.js
```

From a team within, the path begins `../.bulldog/`.
